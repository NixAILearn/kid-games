# 🎮 Kid Games Arcade

A small collection of colorful, free browser games made for kids. No downloads, no ads, no sign-ups. Just open the link and play, on a tablet, phone or computer.

## ▶️ Play now

**👉 https://nixailearn.github.io/kid-games/**

Tip for iPad / iPhone: open the link in Safari, tap the Share button, then **Add to Home Screen** to get an app-style icon.

## 🕹️ The games

| Game | What you do | Modes |
|------|-------------|-------|
| 🌋 **Volcano Builder** | Drag and rotate the puzzle pieces to build the volcano, then watch it erupt! | 10 stages, with pieces getting smaller |
| 🏎️ **Bro & Sis Racers** | Race a rival around 10 countries, dodge ditches and cars, grab boosts | World Tour (3 laps each) and Endless (3 lives) |
| 🫧 **Bubble Pop** | Pop the balloons and stay away from the bombs. Watch for the booster balloon! | 5 stages and Endless (3 lives) |
| 🚀 **Space Snack Pop** | Fly your rocket and collect snacks. Bonus food rounds appear in Endless mode | 5 stages and Endless (3 lives) |
| 🧪 **Math Bottles** | First-grade math: add and subtract, tens and ones, compare numbers, find the missing number. Fill your bottle, earn gems, dress up your character and pick a pet buddy | 3 difficulty levels (or grows with you), read-aloud option |

Every game has a 🏠 button that takes you back to the arcade home page.

## 🎛️ Controls

- **Touch:** drag, tap or use the on-screen buttons.
- **Keyboard:** arrow keys to move or steer, Space to select or fire. In Volcano Builder, Tab / Shift+Tab switches pieces.

## 🛠️ For grown-ups

- Every game is a single self-contained HTML file using plain HTML5 Canvas and JavaScript, with no external libraries.
- Sounds are generated in the browser, so there are no audio files.
- Best scores are saved on the device only (in the browser's local storage). Nothing is collected or sent anywhere.

To run locally, download the files and open `index.html` in any modern browser.

```
index.html      arcade home page
volcano.html    Volcano Builder
car_race.html   Bro & Sis Racers
balloon.html    Bubble Pop
space_pop.html  Space Snack Pop
math_bottles.html  Math Bottles (1st grade math)
```
